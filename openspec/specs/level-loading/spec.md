## Purpose

Определяет, как уровни и ассеты приходят в игру: формат JSON-уровня, манифест уровней, вычисление счётчика земли и поведение при некорректных данных. Обеспечивает data-driven уровни без захардкоженного контента в коде.

## Requirements

### Requirement: Формат уровня
Уровень SHALL загружаться как JSON со следующими полями: идентификатор уровня, ширина и высота в клетках, двумерный массив типов клеток размером `width` × `height`, где каждый элемент — один из типов `wall`, `soil`, `road`. Размеры массива клеток SHALL совпадать с объявленными шириной и высотой.

#### Scenario: Валидный уровень загружается
- **WHEN** загружается JSON с согласованными размерами и известными типами клеток
- **THEN** уровень доступен игре как сетка указанного размера

#### Scenario: Размеры массива не совпадают с объявленными
- **WHEN** в JSON массив клеток не соответствует объявленным `width` и `height`
- **THEN** загрузка уровня завершается ошибкой с указанием причины, игра не стартует с этим уровнем

#### Scenario: Неизвестный тип клетки
- **WHEN** в массиве клеток встречается значение, отличное от `wall`, `soil`, `road`
- **THEN** загрузка уровня завершается ошибкой с указанием причины

### Requirement: Стартовая позиция
Уровень SHALL объявлять стартовую клетку игрока, и эта клетка SHALL иметь тип `road`: игрок начинает на уже замощённой клетке, поэтому в данных это не должна быть земля. Уровень без стартовой позиции SHALL отклоняться с ошибкой — позиция по умолчанию не подставляется.

#### Scenario: Стартовая клетка — асфальт
- **WHEN** загружается уровень, в котором клетка стартовой позиции имеет тип `road`
- **THEN** игрок появляется на этой клетке, счётчик `soil` её не учитывает

#### Scenario: Стартовая клетка — не асфальт
- **WHEN** в уровне стартовая позиция указывает на клетку типа `soil` или `wall`
- **THEN** загрузка уровня завершается ошибкой

#### Scenario: Стартовая позиция не объявлена
- **WHEN** в JSON уровня отсутствует поле стартовой позиции
- **THEN** загрузка уровня завершается ошибкой, позиция не выбирается автоматически

### Requirement: Счётчик земли
При загрузке уровня система SHALL вычислить количество клеток типа `soil` на карте и использовать его как начальный счётчик оставшейся земли.

#### Scenario: Начальный счётчик равен числу клеток soil
- **WHEN** загружается уровень с 25 клетками `soil`
- **THEN** начальный счётчик оставшейся земли равен 25

### Requirement: Манифест уровней
Система SHALL загружать список доступных уровней из манифеста — JSON со списком записей, каждая из которых содержит идентификатор уровня, имя файла с данными уровня и отображаемое имя уровня. Идентификатор записи SHALL совпадать с идентификатором в самом файле уровня.

#### Scenario: Манифест содержит список уровней
- **WHEN** загружается манифест со списком записей уровней
- **THEN** для каждой записи доступны идентификатор, имя файла и отображаемое имя

#### Scenario: Загрузка уровня по записи манифеста
- **WHEN** выбрана запись манифеста
- **THEN** данные уровня загружаются из указанного в записи файла

#### Scenario: Идентификаторы не совпадают
- **WHEN** идентификатор записи манифеста отличается от идентификатора в файле уровня
- **THEN** загрузка завершается ошибкой с указанием расхождения
