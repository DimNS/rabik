## Why

Кандидаты `road` / `soil` / `wall` сейчас не сшиваются сами по себе: стыки держатся на бленде общей кромки (`applySharedRim`) и требуют аккуратности в рантайме, травы `grass1-4` разъезжаются по цвету, а `soil` выглядит пустым пятном без камней. Нужно сделать тайлы самодостаточными — положил рядом и шва нет.

## What Changes

- `road` (`asphalt`): самoсшивающаяся кромка без рантайм-кода — соседние тайлы стыкуются без шва и фона из любого варианта.
- `soil` (`earth`): самoсшивающаяся кромка без рантайм-кода + камни внутри тайла с учётом размера (много мелких, либо один крупный, либо два средних), чтобы влезали и не выглядели пятном.
- `wall` (`grass1-4`): единый базовый зелёный цвет травы вместо четырёх разных палитр; самoсшивающаяся кромка без рантайм-кода; дифференцирующие объекты поверх травы в случайном месте тайла для вариативности:
  - `grass1` — крупные травинки;
  - `grass2` — кусты;
  - `grass3` — одно дерево;
  - `grass4` — камень.
- Детерминизм сохраняется: идентичный seed даёт попиксельно идентичный результат.

## Capabilities

### New Capabilities

- Нет новых capabilities — всё укладывается в существующие требования генерации.

### Modified Capabilities

- `tile-variants`: меняются требования к рецептам `earth`, `asphalt`, `grass1-4` — требование самосшиваемости кромки без рантайма, единый зелёный базис травы, камни в `soil`, объекты на траве `wall` со случайным размещением.

## Impact

- Затронут `scripts/gen-tile-variants.ts` и `scripts/gen-tile-variants.test.ts` (рецепты, кромка, детерминизм).
- Перегенерируются `public/assets/candidates/` и `candidates.json`; визуально проверяется через `tools/gallery.html`.
- Рантайм отрисовки и `wall-coherence` не меняются на уровне API — сшивка переезжает в генерацию, отдельный код сшивки в рантайме не требуется.
