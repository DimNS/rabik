## Context

См. `proposal.md` (Why) и `specs/tile-variants/spec.md` (что требуется). Текущее состояние: `scripts/gen-tile-variants.ts` — фон на периодическом `makeNoise` (сам по себе тайлится), дискретные элементы (травинки, крап) рисуются без учёта края, а межвариантный стык держится на `applySharedRim` — бленде 12px от `EDGE_SEED`-рендера smoothstep-весом. Бленд даёт кольцо и не гарантирует попиксельного совпадения краёв. Палитры `grass1-4` разные, `earth` без камней.

## Goals / Non-Goals

**Goals:**
- Любая пара вариантов одного рецепта стыкуется край-к-краю без шва, без рантайм-кода.
- Единый зелёный базис трав, различия только объектами.
- Камни `soil` по размеру, объекты `wall` в случайном детерминированном месте.

**Non-Goals:**
- Не трогаем рантайм отрисовки, `wall-coherence`, `atlas-generator`, галерею.
- Не вводим новые рецепты и зависимости; только `gen-tile-variants.ts` + тест.

## Decisions

### 1. Перьевая общая рамка + keep-out полоса (испр.: жёсткая копия давала видимую рамку)

Внешний край — чистый `EDGE_SEED`-рендер того же рецепта (вес 1, попиксельный стык между тайлами), внутрь вес сходит на нет smoothstep до 0 на `RIM` (перо поглощает переход рамка↔тайл). Весь дискретный шум — строго внутри `[RIM, TILE-RIM)`, так что в зоне бленда смешиваются только два гладких фона и кольца/гостинга нет.
- Первая итерация (жёсткая копия рамки) отвергнута по визуалу: стык двух независимых шумовых полей внутри тайла читается как тёмная рамка.
- Старый бленд до change'а страдал тем же кольцом по другой причине (мешал дискретные узоры); теперь дискрет заперт в интерьере, бленд смешивает только фон.
- Альтернатива (общий фон из одного сида для всех вариантов, удалить код рамки) — отвергнута: фоны вариантов стали бы идентичными, вариативность упала бы до дискрета.

### 2. Единая зелёная база трав

Один набор констант фона (средний зелёный + диапазоны `makeNoise`), четыре конфига различаются только плотностью/длинной травинок, крапом и объектом. Средний цвет фона одинаков → требование «единый цвет» выполняется конструктивно.
- Альтернатива: подгонять палитры постфактум гистограммой — отвергнута: лишний код ради того, что решается одной константой.

### 3. Объекты поверх травы, позиция из seed

Центр объекта (`cx, cy`) — из того же `mulberry32(seed)` после фона, в центральной зоне (объект гарантированно цепляет центр тайла, рамку не задевает). `grass1` — пучок тонких наклонных тёмно-зелёных штрихов (без неона и большой тени); `grass2` — 2–3 тёмных диска-куста; `grass3` — ствол + 2–3 диска кроны (один, крупный); `grass4` — камень новой техникой (см. решение 5). Кусты/крона — плоские диски общим хелпером «тень + тело + блик», один свет. Детерминизм бесплатен — тот же PRNG-поток.
- Альтернатива: спрайты/шумовые маски — отвергнута: ассеты и код ради того, что диски уже дают.

### 4. Камни `soil` по размеру, целиком внутри

Выбор компоновки первым броском `rand()`: ~40% — 6–9 мелких (`r` 3–6), ~30% — два средних (`r` 9–13), иначе один крупный (`r` 16–22). Центры — rejection sampling внутри `[RIM+r, TILE-RIM-r)`, без пересечений, попыток с запасом.
- Альтернатива: камни через край с заворотом — отвергнута: резаный камень у края выглядит швом; запас 130px позволяет всё разместить внутри.

### 5. Камень «контур + грань» вместо плоского диска (испр.: диски выглядели шарами)

Плоский диск с центральным бликом читается как шар/яйцо. Камень (`grass4`, `earth`) — неровный силуэт из 3 overlapping-лепестков, тёмный контур (подложка `r+1.2`), светлая грань сверху-слева (~40% площади) + малая точка-блик. Контраст выше крапа сохраняется (контур темнее, грань светлее).
- Альтернатива: шумовая маска/полигон со сплайнами — отвергнута: лепестки дают достаточную неровность за ~10 строк.

## Risks / Trade-offs

- [Risk] JPG-компрессия размывает попиксельную идентичность рамки → порог шва в тесте с запасом (средний перепад < 12 уже есть; жёсткая рамка даст ~JPG-шум, а не структуру).
- [Risk] Крупное дерево/камень доминирует в тайле 130px → ограничение радиусов (крона ≤ 24, камень ≤ 22) и приглушённые тона.
- [Risk] Камни `soil` при мелком радиусе неотличимы от крапа → камни крупнее крапа минимум вдвое + обязательный блик/тень.
- [Trade-off] Полоса `RIM` одинакова у всех вариантов рецепта — край статичен, живёт только интерьер; приемлемо: сшивка важнее разнообразия 12px у края.

## Migration Plan

1. Правим только `scripts/gen-tile-variants.ts` (рамка, палитра, камни, объекты).
2. Обновляем пороги/кейсы `scripts/gen-tile-variants.test.ts` под новые требования.
3. Перегенерируем `public/assets/candidates/` + `candidates.json`, визуально проверяем в `tools/gallery.html`. Откат — откат генератора и перегенерация.
