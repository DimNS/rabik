## MODIFIED Requirements

### Requirement: Сборка атласа статичных плиток из JPG

Генератор SHALL сканировать папки `wall/`, `soil/`, `road/` внутри raw-каталога, принимать только файлы `.jpg` со стороной 130 пикселей (файлы с другими расширениями SHALL игнорироваться) и записывать кадр с именем `<строчная буква типа><номер файла без расширения>` (`w307`, `s101`, `r102`, …) размером 130×130 с детерминированными координатами; сортировка по имени файла SHALL определять порядок раскладки. Индексных имён вида `wall_0…wall_N` SHALL NOT быть. Пустая папка типа SHALL означать ноль кадров этого типа; если все три папки пусты или папок нет — генератор завершается с ошибкой без записи. Точная раскладка кадров в `tiles.jpg` (ряды/сетка) — в `design.md`.

#### Scenario: Успешная сборка статики
- **WHEN** в папках `raw/wall/`, `raw/soil/`, `raw/road/` есть файлы 130×130
- **THEN** генератор записывает `tiles.jpg` и `tiles.json`, где каждый кадр имеет имя вида `w307`/`s101`/`r102`, размер 130×130 и не пересекается с другими кадрами

#### Scenario: Неквадратный или неверный размер входа
- **WHEN** файл варианта не квадратный или его сторона не равна 130 пикселям
- **THEN** генератор завершается с ошибкой и не записывает выходные `tiles.jpg` / `tiles.json`

#### Scenario: Сборка нескольких вариантов
- **WHEN** в `raw/wall/` лежат `306.jpg` и `307.jpg` 130×130
- **THEN** в `tiles.json` есть кадры `w306` и `w307` без пересечений с другими кадрами, индексных имён (`wall_0`) и алиаса `wall` нет

#### Scenario: Посторонние файлы игнорируются
- **WHEN** в папке типа лежат файлы с расширениями не `.jpg` (например `notes.txt`, `draft.png`)
- **THEN** сборка успешна, посторонние файлы в атлас не попадают

### Requirement: Совместимость выхода с загрузчиком игры

Выходные JSON SHALL соответствовать формату, который принимает `parseAtlas`: объект `frames` с прямоугольниками `x/y/w/h`, поле `meta.image` с именем PNG, поле `meta.size` с реальным размером PNG; кадры кролика MUST содержать положительный `duration`. Размер тайла (`tileSize`) SHALL браться из любого кадра статики (все кадры — 130×130); привязки к кадру `wall` SHALL NOT быть.

#### Scenario: Загрузка выхода игрой
- **WHEN** игра загружает сгенерированные JSON и PNG через `parseAtlas` / `loadAtlas`
- **THEN** разбор проходит без ошибок, `tileSize` равен 130, и каждый кадр из JSON находится внутри границ PNG

#### Scenario: Длительность кадров анимации
- **WHEN** сгенерирован атлас анимации кролика
- **THEN** каждый кадр `rabbit_0` … `rabbit_8` содержит `duration` больше нуля
