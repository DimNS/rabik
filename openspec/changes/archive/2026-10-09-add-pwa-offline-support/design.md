## Context

См. `proposal.md` (Why) — мотивация там, здесь только исходное состояние.

- `index.html` в корне, грузит `./dist/index.js`; `scripts/build.sh` собирает в `dist/`, копирует `public/` → `dist/public/`, `index.html` → `dist/index.html` (с заменой пути JS), `favicon.ico` → `dist/`. Раздаётся именно `dist/`.
- `dev.sh` раздаёт корень (`bunx serve .`), страница — корневой `index.html`.
- Манифеста, иконок нужных размеров и Service Worker нет. `icon.png` — 120x100 (для installability не годится), зато есть `public/assets/ui/logo.png` 1080x833 как исходник иконок.
- В `scripts/atlas-codec.ts` уже есть `decodePng` / `encodePng` / `decodeJpg` без новых зависимостей — переиспользуем для генерации иконок.
- Кэшируемое множество известно заранее и статично: `index.html`, `index.js`, манифест, иконки, `public/assets/sprites/*`, `public/assets/ui/*`, `public/data/levels/*`.

## Goals / Non-Goals

**Goals:**

- Установка на главный экран Android/iOS с запуском в `standalone` без браузерного chrome.
- Офлайн-запуск после одного онлайн-визита; обновление кэша при новой сборке без ручной чистки.
- Ноль новых npm-зависимостей, сборка остаётся одним `scripts/build.sh`.

**Non-Goals:**

- Push-уведомления, background sync, share target — не нужны игре без бэкенда.
- Пер-девайсные iOS splash-скрины — достаточно `apple-touch-icon` + `theme-color`.
- Синхронизация прогресса с сервером — прогресс и так локальный (`localStorage`), SW его не трогает.

## Decisions

### D1: PWA-файлы в корне по образцу `favicon.ico`, сборка их копирует

Новые файлы `manifest.webmanifest`, `sw.js`, каталог `icons/` лежат в корне репозитория (как `index.html` и `favicon.ico`). `index.html` ссылается на них относительными путями (`./manifest.webmanifest`, `./sw.js`), `build.sh` копирует все три в `dist/`. Относительные пути работают и в dev (корень), и в проде (`dist/` как корень раздачи, в т.ч. при хостинге в подпути).

Альтернатива — держать исходники в `public/` — отвергнута: SW обязан лежать в корне scope (иначе не покрывает `index.html`), а манифест рядом со страницей проще копировать тем же приёмом, что `favicon.ico`.

### D2: `sw.js` — статичный файл с версионированным кэшем, копируется как есть

SW без шаблонизации: `const CACHE = 'oneway-v1'`, bump версии — правкой одной строки. Список precache между маркерами `@generated:precache` обновляет `scripts/gen-sw.ts` (сканирует `icons/`, спрайты, UI и уровни), `build.sh` запускает его перед копированием — новые уровни подхватываются сами. `install` — precache shell, `activate` — `skipWaiting` + `clients.claim` + удаление кэшей не текущей версии, `fetch` — cache-first для same-origin GET с сетевым фолбэком и `put` успешных ответов, навигации — фолбэк на `index.html`.

Альтернативы: Workbox — отвергнут (новая зависимость ради статики); runtime-only кэширование без precache — отвергнуто (первый офлайн-заход отдаст битую страницу, нарушает спеку).

### D3: Иконки генерирует `scripts/gen-icons.ts` на `atlas-codec.ts`

Новый скрипт: `decodePng(logo.png)` → центральный квадратный кроп → даунскейл до 512/192/180 на тёмном фоне `#111` (цвет игры) → `encodePng` в `icons/icon-512.png`, `icons/icon-192.png` (оба + `purpose: any maskable` в манифесте), `icons/apple-touch-icon.png` 180px. Файлы коммитятся, в сборку попадают копированием. Ресемпл — ближайший сосед / билинейный на чистых массивах, без новых библиотек.

Альтернатива — масштабировать внешним инструментом или тянуть sharp — отвергнута (новая зависимость / недетерминизм окружения). SVG-иконки вместо PNG — отвергнуты (installability-критерии Chrome требуют PNG 192/512).

### D4: Регистрация SW в `src/index.ts` — охраняемая и ленивая

`if ('serviceWorker' in navigator)` → регистрация `./sw.js` после `window.load` (или `requestIdleCallback`), ошибки глотаются в `console.warn`. Игровой цикл, загрузка атласов и уровней не меняются; в неподдерживаемых браузерах — тихий no-op.

## Risks / Trade-offs

- [Зависший старый кэш после деплоя] → версионированное имя кэша + чистка чужих версий в `activate` + `skipWaiting/clients.claim`.
- [Хостинг в подпути] → все пути относительные (`start_url: ./index.html`, `scope: ./`), абсолютных нет.
- [Неквадратный логотип] → центральный кроп на фоне `#111`; иконка декоративна, точная передача логотипа не требуется.
- [iOS-ограничения PWA] → принимаются; базовые install + offline на iOS работают, остальное — Non-Goals.
- [Раздувание precache при росте числа уровней] → список уровней мал (единицы JSON); при росте — генерировать список кэша из `public/data/levels/index.json` на этапе сборки.

## Migration Plan

- Деплой: `bun run build` (генерирует иконки один раз через `gen-icons.ts`, дальше обычная сборка) → раздать `dist/`.
- Откат: перераздать предыдущий `dist/`; SW подхватит меньшую версию кэша как новую и заменит текущую.
- Данные: миграций нет, `localStorage`-прогресс не затрагивается.
