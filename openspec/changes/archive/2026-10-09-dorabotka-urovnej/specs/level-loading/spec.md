## MODIFIED Requirements

### Requirement: Манифест уровней
Система SHALL загружать список доступных уровней из манифеста — JSON со списком записей, каждая из которых содержит идентификатор уровня и опциональные `seed` и `difficulty` (`easy` | `normal` | `hard`). Идентификаторы записей SHALL быть уникальны. Непустые `seed` SHALL быть уникальны, кроме значения-заглушки `"---"` (ручной уровень без генерации), которое в проверке уникальности SHALL NOT участвовать. Идентификатор записи SHALL совпадать с идентификатором в самом файле уровня.

#### Scenario: Манифест содержит список уровней
- **WHEN** загружается манифест со списком записей уровней
- **THEN** для каждой записи доступны идентификатор, seed и сложность

#### Scenario: Загрузка уровня по записи манифеста
- **WHEN** выбрана запись манифеста
- **THEN** данные уровня загружаются из указанного в записи файла

#### Scenario: Идентификаторы не совпадают
- **WHEN** идентификатор записи манифеста отличается от идентификатора в файле уровня
- **THEN** загрузка завершается ошибкой с указанием расхождения

#### Scenario: Дубликат id отклоняется
- **WHEN** в манифесте две записи с одинаковым `id`
- **THEN** разбор манифеста завершается ошибкой с указанием дублирующегося `id`

#### Scenario: Дубликат seed отклоняется
- **WHEN** в манифесте две записи с одинаковым непустым `seed` (кроме `"---"`)
- **THEN** разбор манифеста завершается ошибкой с указанием дублирующегося `seed`

#### Scenario: Заглушка seed не считается дубликатом
- **WHEN** в манифесте несколько записей с `seed` `"---"` или без `seed`
- **THEN** разбор манифеста успешен, проверка уникальности их пропускает
