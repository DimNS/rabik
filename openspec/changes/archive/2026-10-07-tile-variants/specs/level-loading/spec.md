## MODIFIED Requirements

### Requirement: Формат уровня

Уровень SHALL загружаться как JSON со следующими полями: идентификатор уровня, ширина и высота в клетках, двумерный массив типов клеток размером `width` × `height`, где каждый элемент — один из типов `wall`, `soil`, `road`. Размеры массива клеток SHALL совпадать с объявленными шириной и высотой. Уровень MAY содержать поле `tileSeed` — целое неотрицательное число; при отсутствии поля система SHALL вычислять seed как 32-битный хэш строки `id` уровня. Нецелое или отрицательное `tileSeed` SHALL отклоняться с ошибкой валидации.

#### Scenario: Валидный уровень загружается
- **WHEN** загружается JSON с согласованными размерами и известными типами клеток
- **THEN** уровень доступен игре как сетка указанного размера

#### Scenario: Размеры массива не совпадают с объявленными
- **WHEN** в JSON массив клеток не соответствует объявленным `width` и `height`
- **THEN** загрузка уровня завершается ошибкой с указанием причины, игра не стартует с этим уровнем

#### Scenario: Неизвестный тип клетки
- **WHEN** в массиве клеток встречается значение, отличное от `wall`, `soil`, `road`
- **THEN** загрузка уровня завершается ошибкой с указанием причины

#### Scenario: Явный seed
- **WHEN** уровень содержит `"tileSeed": 42`
- **THEN** загрузка успешна и варианты тайлов выбираются от seed 42

#### Scenario: Seed по умолчанию из id
- **WHEN** поле `tileSeed` отсутствует
- **THEN** загрузка успешна и seed равен хэшу `id`; два уровня с разными `id` с высокой вероятностью получают разные seed
