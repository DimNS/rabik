## Why

Сейчас игра сразу запускает первый уровень из манифеста без входа, выбора уровня и обратной связи о победе/поражении (результат только пишется в `console.log`). Нужно добавить окна входа, выбора уровней и модальные окна победы/поражения/меню, чтобы появился законченный игровой цикл на готовых ассетах.

## What Changes

- Добавить окно входа с логотипом (`public/assets/ui/logo.png`) и кнопкой play (`public/assets/ui/button/play.png`), ведущей к выбору уровней.
- Добавить окно выбора уровней с артом внизу (`public/assets/ui/lvlsel/art.png`), кнопками уровней: непройденный (`ui/lvlsel/none.png`), пройденный (`ui/lvlsel/done.png`); запуск уровня по клику.
- Хранить список пройденных уровней в `localStorage` и отображать статус кнопок по нему.
- Во время игры показать кнопку меню в углу (`public/assets/ui/button/back.png`), открывающую модальное окно меню (`ui/modal/menu.png`).
- Добавить модальное окно победы (`ui/modal/win.png`, кнопки back/next) при `solved` и модальное окно проигрыша (`ui/modal/fail.png`, кнопки back/restart/skip) при `stuck`.
- Семантика кнопок модалок: back — возврат к выбору уровней, restart — перезапуск текущего уровня, skip/next — переход к следующему уровню по манифесту.

## Capabilities

### New Capabilities

- `entry-screen`: окно входа (логотип, кнопка play, переход к выбору уровней).
- `level-select`: окно выбора уровней (список из манифеста, статусы done/none, хранение прогресса в `localStorage`).
- `game-modals`: окна во время игры (кнопка меню в углу; модалки победы, поражения и меню с кнопками back/restart/skip-next).

### Modified Capabilities

— нет; существующие требования `game-rules` (флаги `solved`/`stuck`) и `level-loading` (манифест уровней) переиспользуются без изменения.

## Impact

- Затронуты: точка входа `src/index.ts` (bootstrap сейчас грузит только первый уровень), новый UI-слой поверх canvas (`src/view/` + `index.html`), загрузка `ui/`-ассетов окон, прогресс в `localStorage`.
- Зависимости/системы: формат уровней и манифест (`src/data/levels-loader.ts`, `public/data/levels/`) не меняются; игровое ядро (`src/core/game-rules.ts`) не меняется — UI только читает `solved`/`stuck`.
