# Rabik — замости всю землю

Пиксель-пазл про кролика-дорожника: катись по земле и асфальтируй её в дорогу. Замости всю землю — уровень решён. Загони себя в тупик — игра окончена.

## Управление

- Клавиатура: стрелки `↑ ↓ ← →` (остальные клавиши игнорируются).
- Тач-экран: свайп `↑ ↓ ← →` (остальные жесты игнорируются).

## Правила

- Ходить можно только на `землю`. `трава`, `дорога` и выход за край сетки — непроходимы.
- Клетка, на которую встал кролик, становится `дорогой`; счётчик `земли` уменьшается на 1.
- Ход на `дорогу` запрещён — маршрут необратим, вернуться нельзя.
- Стартовая клетка — уже `дорога`, в условии победы не участвует.
- Победа: `земли` не осталось.
- Тупик: после шага вокруг нет соседней `земли`, а земля ещё осталась.

## Разработка

### Запуск

Нужен [Bun](https://bun.sh).

```bash
bun install     # или make install
bun run dev     # watch-сборка + локальный сервер
bun run build   # продакшн-сборка в dist/
bun run test    # тесты
bun run check   # typecheck + lint + тесты
make ai-check   # то же, что check + защита от правок package.json
```

### Структура

```
src/
  core/    правила (game-rules.ts), состояние (game-state.ts), типы уровня
  view/    раскладка тайлов (layout.ts, тайл ≤ 130px), рендерер (renderer.ts),
           спрайт-атлас и анимация
  input/   клавиатура, свайпы, декодирование направлений
  loop/    игровой цикл на requestAnimationFrame
  data/    загрузка уровней и манифеста
  index.ts bootstrap: canvas → атласы → уровень → цикл
public/
  data/levels/   уровни (level-*.json) и манифест index.json
  assets/sprites/ атласы tiles.* и rabbit.*
scripts/   генераторы: gen-atlas.ts (сборка атласов из public/assets/raw/)
tools/     gallery.html — оффлайн-галерея raw-кадров и атласа
openspec/  спеки и история изменений
```

### Уровни

Уровень — JSON: `id`, `width`/`height`, матрица `tiles` из явных кадров (`w403`, `s301`, `r101`, …; префикс `w`/`s`/`r` задаёт тип `wall`/`soil`/`road`), стартовая клетка `start` (обязана быть кадром `r*`). Список уровней — в `public/data/levels/index.json` (`id` записи обязан совпадать с `id` файла). Инструкция маппинга кадров — в спеках `tile-mapping`.

### Спрайты

Тайлы — квадрат 130px, кадры именованные (`w307`, `s101`, `r102`, …) берутся из данных уровня напрямую; ход на `s201` меняет кадр на `r102`. Кролик — стрип 1170×130 (9 кадров 130×130, `rabbit_0…rabbit_8`), анимация зациклена по времени и не сбрасывается на ходах. Пересборка: `make atlas`. Рендер с `imageSmoothingEnabled = false` и `image-rendering: pixelated`, поле занимает всё окно.
