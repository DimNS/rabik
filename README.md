# OneWay — замости всю землю

Пиксель-пазл про кролика-дорожника: катись по земле (`soil`) и асфальтируй её в дорогу (`road`). Замости всю землю — уровень решён. Загони себя в тупик — игра окончена.

## Запуск

Нужен [Bun](https://bun.sh).

```bash
bun install     # или make install
bun run dev     # watch-сборка + локальный сервер
bun run build   # продакшн-сборка в dist/
bun run test    # тесты
bun run check   # typecheck + lint + тесты
make ai-check   # то же, что check + защита от правок package.json
```

## Управление

- Клавиатура: стрелки `↑ ↓ ← →` (остальные клавиши игнорируются).
- Тач-экран: свайп, ход идёт по доминирующей оси; короткий жест игнорируется.
- Ввод буферизуется: максимум один ход за кадр, лишние не теряются.

## Правила

- Ходить можно только на `soil`. `wall`, `road` и выход за край сетки — непроходимы.
- Клетка, на которую встал кролик, становится `road`; счётчик `soil` уменьшается на 1.
- Ход на `road` запрещён — маршрут необратим, на старт и на свой асфальт вернуться нельзя.
- Стартовая клетка — уже `road`, в условии победы не участвует.
- Победа: `soil` не осталось → в консоли `Уровень решён: вся земля замощена`.
- Тупик: после шага вокруг нет соседней `soil`, а земля ещё осталась → в консоли `Игра окончена: ходов больше нет`. Победа приоритетнее тупика.
- Кролик по умолчанию смотрит вверх и поворачивается в сторону каждого шага.

## Структура

```
src/
  core/    правила (game-rules.ts), состояние (game-state.ts), типы уровня
  view/    раскладка тайлов (layout.ts, тайл ≤ 130px), рендерер (renderer.ts),
           спрайт-атлас и анимация
  input/   клавиатура, свайпы, декодирование направлений
  loop/    игровой цикл на requestAnimationFrame
  data/    загрузка уровней и манифеста
  index.ts bootstrap: canvas → атласы → уровень → цикл
public/
  data/levels/   уровни (level-*.json) и манифест index.json
  assets/sprites/ атласы tiles.* и rabbit.*
scripts/   генераторы: gen-tile-variants.ts (JPG-кандидаты 130×130),
           gen-atlas.ts (сборка атласов)
tools/     gallery.html — оффлайн-галерея кандидатов и атласа
openspec/  спеки и история изменений
```

## Уровни

Уровень — JSON: `id`, `width`/`height`, матрица `tiles` из `wall`/`soil`/`road`, стартовая клетка `start` (обязана быть `road`). Список уровней — в `public/data/levels/index.json` (`id` записи обязан совпадать с `id` файла). Необязательное поле `tileSeed` задаёт раскладку вариантов тайлов; без него seed вычисляется из `id`.

## Спрайты

Тайлы — квадрат 130px, варианты кадров `wall_N`/`soil_N`/`road_N` выбираются детерминированно по `(x, y, tileSeed)`. Кролик — стрип 1170×130 (9 кадров 130×130, `rabbit_0…rabbit_8`), анимация зациклена по времени и не сбрасывается на ходах. Пересборка: `make candidates` → отбор в галерее → `make atlas`. Рендер с `imageSmoothingEnabled = false` и `image-rendering: pixelated`, поле занимает всё окно.
